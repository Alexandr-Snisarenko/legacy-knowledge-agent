# Legacy Knowledge Agent

Legacy Knowledge Agent — система для поиска, анализа и интерпретации инженерной документации долгоживущих информационных систем.

Проект ориентирован на большие наборы разнородной документации — Word, Excel, Visio, HTML, PDF и другие источники — которые накапливались годами, частично устарели и могут противоречить друг другу.

Цель системы — не просто находить документы, а давать обоснованные ответы на инженерные вопросы с учётом:

- релевантности и актуальности источников;

- истории изменений системы;

- противоречий между документами;

- происхождения и степени доверия к информации;

- ссылок на документы и фрагменты, на которых основан ответ.

В перспективе проект должен объединить document ingestion, RAG, анализ конфликтов, evidence-based ответы и агентные workflows в единую платформу инженерных знаний.
